# 🇱🇹 Build Your First End to End Lakehouse Solution during Big Data CONFERENCE Europe 2025 - AI, Cloud and Data Conference Vilnius, Lithuanian

Welcome to [Big Data Conference Europe 2025](https://bigdataconference.eu/) 🇱🇹 — an event dedicated to advancing the future of AI, cloud, and data innovation.

This workshop gives you practical, hands-on experience in building a complete lakehouse solution using Microsoft Fabric. You’ll learn how to integrate, transform, and manage data across the entire lifecycle with pipelines, dataflows, notebooks, and Spark. You’ll also see how BI analysts and data scientists leverage the lakehouse to accelerate insights and strengthen decision-making.


> [!IMPORTANT]
> Join a group on Whatsapp: https://chat.whatsapp.com/Ffj9gyzwMjDEq1mlpM4UnF


---

**Workshop Goals**
- Master Microsoft Fabric Data Integration and Data Engineering.
- Develop a complete data workflow: ingestion, preparation, and serving.

**Project Context: Urban Mobility Transformation**
- Use Microsoft Fabric to analyze New York City's taxi data for improved urban planning and transportation safety.

**Lakehouse Solution Benefits**
- Unified urban transport data analysis.
- Enhanced fleet management and traffic forecasting.
- Data-driven urban development insights.
- Improved transportation reliability and safety.
- Adaptable data infrastructure for future urban mobility trends.
